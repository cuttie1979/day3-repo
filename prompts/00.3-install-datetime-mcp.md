# S3 · datetime MCP

**A nap 12. diájának eszköze** — és szándékosan a legegyszerűbb MCP: egyetlen dolog, a pontos idő.

**Rust szerver**, tehát az 1. lépés nélkül nem fordul le. A saját gépeden a bináris a
`/home/user/mcps/bin/mcp-datetime` (és ugyanott a `guairdian-mcp`), tehát a `mcps/bin/` közös gyűjtőhely
— érdemes ugyanoda tenni, nem szétszórni.

**Amit utána ellenőrzünk:** az MCP válaszol (`datetime_get_current_date_time`), és hogy a konfig **a
projektben** jött létre, nem globálisan.

```
Please install the datetime MCP from this repository: https://github.com/GeorgeHahn/mcp-datetime

It is a Rust server: build it from source with cargo (release), and put the binary in /home/user/mcps/bin/mcp-datetime, next to the other MCP binaries.

Then use the opencode-configuration skill to configure it as an MCP service for the current project. Use the absolute path to the binary in the command, and verify afterwards that the MCP answers a call.
```
