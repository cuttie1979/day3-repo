# 17 · mempalace MCP

**A nap 13. diájának eszköze** — ez teszi a kutatást jegyzetből kontextussá. A napon itt töltöd be a
14 kutatás eredményét.

**Egy különbség a saját gépedhez képest:** ott a mempalace `~/.local/bin/mempalace-mcp` (uv tool
install), a prompt viszont **külön venv-et** kér a mappában. Mindkettő működik; a venv jobban elkülönít,
az uv tool egyszerűbb. A prompt a venv-et írja le, mert az a "saját mappa" szándékod — de ha a napon
egyszerűbb kell, `uv tool install` és kész.

**Amit javítottam:** `~/AIHome_Mempalace` → **`~/AIHome/mempalace`**. A `~` gyökere alá nem teszünk
mappát; a szabály az, hogy minden az `AIHome/` alatt lakik.

**Amit utána ellenőrzünk:** az MCP válaszol, és a `mempalace_search` visszaad valamit — a napon ez lesz
a mérce.

```
Please install the following MCP service: https://github.com/mempalace/mempalace into the folder ~/AIHome/mempalace

Create that folder, make a separate virtual environment in it with uv (uv venv), install mempalace into that environment, and note the absolute path of the MCP launcher it provides — the configuration will need it.

Once mempalace is installed, configure it as an MCP service using the opencode-configuration skill, for the current project, with the absolute path to the launcher and a 60 second timeout.

Once mempalace is configured, initialise it, but no mining is required. Verify that a search call answers.
```
